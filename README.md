# EXEC_QUIVE=VIDEO/. 使用说明

## 1. 概述

EXEC_QUIVE=VIDEO/. 是一款基于小丸工具箱的「一图流」批量生成工具。
程序调用小丸工具箱自带的 ffmpeg，将**一张封面图**与**多条音频**合成为 FLV 视频：画面为封面静帧，音轨为原音频直拷。

- 支持直接拖入封面图、音频文件或文件夹。
- 添加文件夹时，会递归读取其中的音频文件。
- 输出文件与对应音频放在同一目录，扩展名为 `.flv`。

---

## 2. 运行环境与启动方式

### 运行环境

- Windows 操作系统
- Python 3（需包含 tkinter，通常随 Python 官方安装包自带）
- 已安装小丸工具箱。程序需要使用其中的：

  ```text
  <小丸安装目录>\tools\ffmpeg.exe
  ```

  例如安装在 D 盘时，路径为 `D:\小丸\tools\ffmpeg.exe`。

在界面顶部「小丸目录」中选择实际安装目录，程序会记住该路径。  

选定目录后，程序会读取同目录下 `xiaowan.exe.Config` 中的一图流参数（帧率 `OnePicFPS`、画质 `OnePicCRF`）。若配置文件不存在，则默认使用 **1 fps / CRF 24**。

### 启动方式

以下两种方式任选其一：

- 双击 `EXEC_QUIVE_VIDEO.bat`
- 或在程序所在目录执行命令：

```bash
python EXEC_QUIVE_VIDEO.py
```

### 可选依赖

建议安装 `tkinterdnd2`，可获得更稳定的拖放体验；未安装时仍可使用系统拖放功能。

```bash
pip install tkinterdnd2
```

## 4. 基本操作流程

1. **指定小丸目录**  
   若未自动识别，单击「小丸目录」旁的「选择…」，选中小丸工具箱的安装目录。  
   该路径会自动记住，下次启动无需再选。

2. **选择封面图**  
   单击封面图旁的「选择…」，或将图片直接拖入窗口。  
   若一次拖入多张图片，程序只使用第一张。

3. **添加音频**  
   单击「添加文件」或「添加文件夹」，也可以将音频或文件夹直接拖入窗口。  
   同一文件不会重复加入列表。

4. **设置文件名前缀（自定义）**  
   在「文件名前缀」中填写固定文字。非法文件名字符会被自动去掉。  
   界面会显示示例文件名，便于核对。

5. **开始生成**  
   确认封面和音频无误后，单击「开始批量生成」。  
   处理过程中可单击「停止」中断后续任务；当前正在处理的那一条会继续完成。

## 5. 输出命名

输出文件与源音频位于同一文件夹，命名规则为：

```text
{前缀}{音频主文件名}.flv
```

示例：

| 音频文件 | 前缀 | 输出文件 |
|----------|------|----------|
| `01.曲名.wav` | （空） | `01.曲名.flv` |
| `01.曲名.wav` | `2_` | `2_01.曲名.flv` |

封面图、前缀、小丸目录会自动记住，下次启动时恢复。
选择封面图与添加音频分别记住各自上次使用的文件夹，互不影响。

---

## 6. 编码方式

程序按小丸「一图流」方式调用 ffmpeg，主要步骤为：

1. 将封面转为 JPG（若已是 JPG / JPEG 则直接复制）。
2. 按音频时长生成静帧 H.264 视频（`libx264`）。
3. 将视频与原音频封装为 FLV；视频、音频均使用 `-c copy`，不重编码音轨。

帧率和 CRF 来自小丸配置，不在本程序界面中修改。

因旧版小丸 ffmpeg 对中文路径支持较差，程序会在临时目录中使用英文临时文件名进行处理，完成后再写回目标 `.flv`。

## 7. 支持的文件格式

### 封面图

```text
.jpg  .jpeg  .jfif  .png  .bmp  .webp  .tif  .tiff
```

### 音频

```text
.wav  .flac  .mp3  .m4a  .aac  .ogg  .wma
.ape  .tak  .tta  .aiff  .aif  .opus  .ac3
```

## 8. 其他功能

- **已有同名 flv 则跳过**（默认开启）  
  若目标 `.flv` 已存在，则跳过该条音频，避免覆盖。

- **停止**  
  中断尚未开始的后续任务。已完成的文件会保留。

- **日志**  
  分别标记 `[完成]`、`[跳过]`、`[失败]`。结束后汇总成功、跳过、失败数量。

---

## 9. 注意事项

- 若未找到 `tools\ffmpeg.exe`，请在顶部重新选择小丸安装目录。未指定有效目录时无法开始生成。
- 请先在小丸工具箱中确认一图流的帧率与 CRF，本程序会沿用该设置。
- 输出始终为 `.flv`，并与对应音频放在同一目录。
- 处理过程使用临时目录，结束后会自动清理。
